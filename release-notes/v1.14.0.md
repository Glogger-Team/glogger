## What's Changed since v1.13.2

### New
- Gift Watcher can add a whole zone at once. It sorts each zone by giftable quantity, so favour runs take one click.
- Quick search now opens the matching trained skill. It expands the group and scrolls the row into view.
- Farming gains a Sources tab that lists gains without a known source.
- Combat Wisdom labels monsters as elite, named, or unknown. It explains elite timers.

### Fixed
- Item picker stacks its panels on narrow screens. It also closes with Esc.

### Improved
- Esc now closes only the topmost dialog, menu, or dropdown. It returns focus to the control that opened it.
- Vendor context menu shares the Esc stack, so one Esc closes only the menu.
- Charts now use theme text colors for labels, axes, and totals.
- Small text now stays at or above 10 px.
- Data Browser and Help now stack their panels on narrow portrait screens.
