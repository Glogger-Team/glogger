## What's Changed since v1.15.0

### New
- Stall counts rebuild from a fresh shop-log book in one click. The preview matches the History window.

### Fixed
- Settings files with a missing key now use the default value. A dropped field can no longer break every save.
- The Help Known Issues list regains its corrected Statehelm entry. It also gains verified entries from a repo survey.
- Settings screens gain corrected copy. Saved settings still persist after the dead-field removal.
- The Hoplology to-study list no longer shows double-affix crafted names. Batch equipment fallback applies to known affix pairs only.
