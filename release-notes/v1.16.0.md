## What's Changed since v1.15.0

### New
- Stall counts rebuild from a fresh shop-log book in one click. This requires you to empty and refill your shop. This is not fun. I know this. There is very little I can do without shop inventory exports. I am considering removing stall tracking entirely. Give me feedback on the glogger thread on discord on what you would like to see.

### Fixed
- Settings files with a missing key now use the default value. A dropped field can no longer break every save.
- Updated the Known Issues list in the Help menu to be more accurate.
- Quick accuracy pass on the text in the settings menu.
- Hoplology to-study list should no longer show items you cannot study.
