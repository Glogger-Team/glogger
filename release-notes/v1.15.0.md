## What's Changed since v1.14.0

### New

- Stall inventory gains reset tools. Clear one row, zero all stock, or rebuild counts from the shop log.
- The backend adds a skillbook lookup by skill. It accepts display name, internal name, or numeric ID. Books with no known skill group under Unknown.

### Fixed
- Sent coins now reduce the wallet. "Sent N coins to a player" records a loss.
- Rez counting no longer drops repeats. Same-phrasing repeats always record. The dedup guard covers cross-phrasing pairs only.
- Poem arrow keys stop when an overlay opens. Page-flip no longer runs under QuickSearch, DataBrowser, or dialogs.
- Stall stock writes serialize on one busy flag. A bulk zero-out can no longer interleave with a save or delete.
- Confirm dialogs recheck busy state on resolve. A write that starts while the dialog sits open blocks the stale confirm.

### Improved
- Partial bulk resets now say so. A character switch mid-loop stops the loop and reports how many items it zeroed.
- Charts share one palette and theme reader. Donut and trend charts draw from the same ten colors.
- Chart tooltips follow the theme. Background and border read surface tokens at render time.
- Tooltips and shared micro text use the type scale. Item, quest, and recipe tooltips drop fixed pixel sizes.
- Six panels drop hard-coded hex colors for theme tokens. Skill detail, recipe panel, skill browser, farming cards, and item tooltips follow the active theme.
- Chat senders and muted text use theme tokens. Unknown channels fall back to secondary text for contrast.
